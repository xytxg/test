# 小说榜单、缓存与换源更新

- 榜单改为顶部分组、左侧栏目、右侧封面与排名列表；读取书源实际配置，不伪造票数或热度。
- 修复 iOS 首次榜单加载竞争、Android 切换分组保留旧结果的问题。原生操作测试覆盖首屏出书、切换栏目和分组、详情进入下载页。
- 修复真实合集的分组标题、JS 生成请求选项、部分脚本兼容和二进制正文处理。新增 Android 受限 Rhino 引擎。
- 详情和阅读页加入缓存 / 下载：后 50 章、后 200 章、全本；预取可选关闭、3、10、20 章。保持应用前台，失败后保留完成章节、可继续下载，已缓存文字可离线阅读。
- 书籍换源搜索同名同作者候选；新目录优先按章节标题接续，匹配不到则按序号限定范围，从章首阅读。正文缓存和脚本书籍变量按来源隔离。
- 保留上一版红果当前 Medusa 取流及筛选条件修复。

本轮使用用户提供的合集 1335：164 个来源中，对普通文本范围 136 个检查发现解析，并抽样执行完整链路。七猫普通文字书、乐读、望书阁已有正文及缓存验证；不是 164 个源全部可用。

已知限制：番茄这一合集源还依赖未完成的 Java I/O 兼容能力；书旗抽样目录为空；部分来源 403 / 超时。图片正文不支持，显示明确提示。Android EPUB 导入、系统后台下载服务仍未提供。

验收记录：仓库 `docs/novel-validation-20261117.md`。原生截图用合成书籍验收布局；真实来源结果单独记录。下载 Assets 中的 APK / IPA，校验见 SHA256SUMS.txt。
