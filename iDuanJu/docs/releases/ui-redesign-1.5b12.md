i短剧 UI 重设计版（iOS 1.5 build 12 / Android 1.5.12）

- 首页、找剧、详情、小说（搜索 / 榜单 / 书源 / 缓存）与播放器按新设计稿重做，浅色 / 深色双主题。
- 播放器：横屏顶部标题与技术信息、底部进度与带标签的功能按钮，加深底部渐变；30 集分组选集；切集与自动连播不再弹出中间播放控件，标题和进度常驻。
- 横竖屏中间区域滑动切集，两侧调亮度 / 音量；锁屏、拖动进度、面板打开时不误切集。修复进度条单击跳转偶发无效。
- Android：播放时保持屏幕常亮（暂停 / 结束 / 离开播放器后释放）；找剧与首页返回时保留数据、筛选和滚动位置，不再重新加载。
- 修复 Xcode 26.3 Release 编译时首页 hero 高度表达式类型推导超时。

验证：本地模拟器回归（STVTests 182 项、播放器 UI 18 项、小说预览 UI）通过；两个依赖 Apple 实网的预取测试不在离线回归内。截图验收使用本地测试片源与合成书源，本轮没有真机画中画与流畅度验收。
