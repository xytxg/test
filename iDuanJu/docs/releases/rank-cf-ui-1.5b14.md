# i短剧 iOS 1.5 b14 / Android 1.5.14 — 排行榜、小说阅读及界面修正版

本次预发布合并真实书源兼容、小说详情/阅读器、Android首页及双端播放器修复。b13仅打包未发布，本次使用全新b14标签，不移动旧标签。

## 本次修复

- 小说排行榜：修正Legado选择器/JS上下文、真实筛选控件和来源内筛选状态持久化；筛选后重建当前分类URL、重置分页，防止后台脚本覆盖新选择。
- 使用用户提供的1335合集实测七猫→爽文→无敌天命→1694章目录→真实正文；验证相邻章预取、取消后不写入过期响应及离线前后章导航。
- Android小说详情恢复封面、作者/来源/简介和底部操作；阅读器采用与现有iOS核心布局对应的原生分页、覆盖式菜单、设置、目录/全文缓存搜索、翻页手势、主题和连续滚动位置恢复。iOS既有阅读器生产视觉未改，增加离开时预取取消。
- Android首页：修复长标题和字体指标挤压“查看详情”，保留紧凑白色按钮并提供至少48dp点击区域；元数据、分页圆点互不覆盖，适应窄屏/较大字体。
- 双端播放器：视频实际渲染边界不随控制层展开/收起改变；收起后仅小标题和底边细进度，无大面积渐变。详情稀疏指标不再显示巨大单项卡，也不编造缺失数据。
- 黄果Cloudflare：识别后显示“需要验证/去验证/重试”，通过可见WebView由用户手动操作；不自动解题或点击挑战，不保证硬封锁可通过。

## 已知限制（请先阅读）

- **不是全部书源已恢复**：此前105个有发现规则文本书源的列表探测，iOS63个、Android68个成功；本次未重跑全源扫描。列表成功不保证所有正文、付费内容可读。部分站点仍403、502、TLS错误或超时，月色部分目录解码仍有限制。
- 本次验证的是小说**核心视觉和操作路径**，不宣称100%功能或像素一致。Android高级TTS/后台语音、全部可选远程字体安装/删除生命周期、所有异常来源的完整换源交互尚未完整验证。系统字体/字形/分页因系统和视口不同，不复制Apple专有字体。
- 旧Android书籍没有保存的导入时间显示“—”，不伪造历史日期。
- 同步HTTP取消不代表底层请求立即中断；过期结果会在写入缓存前丢弃。历史探针保留`readerParityComplete=false`，它不是完整功能验收结论；请以逐项实测记录及上述限制为准。
