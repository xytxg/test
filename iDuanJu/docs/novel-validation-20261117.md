# 小说榜单、下载与换源验收（2026-11-17）

本轮使用用户提供的真实合集测试，不能将“JSON 导入成功”或“栏目名称显示出来”当成书源可用。榜单、搜索、目录、正文、离线缓存分别记录结果。

## 测试输入与范围

- 合集地址：<https://www.yckceo.com/yuedu/shuyuans/json/id/1335.json>
- 下载快照包含 164 个源，110 个配置了 `exploreUrl`；快照 SHA-256：`874efe33cbe38b7dcf830704b5bd0614b9485fe1974a20d9c09030ebec07df30`。
- 本轮执行普通文本源 136 个；另外 28 个非目标类型或其他分组未作内容访问测试。完整原始合集不提交、不内置到安装包。
- Swift 使用应用生产 Legado 引擎编译的 CLI，Android 使用生产 `NovelSources` / `NovelScript`。每源独立进程、有超时，避免单个脚本卡住整批。
- 所有目标源检查发现配置；选取 12 条 iOS / 10 条 Android 来源记录继续执行真实网络流程。没有测试每一本书、每个榜单和全部章节。
- 真实网络检查仅记录数量和错误，不把正文、签名、设备状态或登录凭据放入仓库。

## 已修复的客户端问题

- 发现配置中的“分类”“榜单”等标题和空链接作为分组处理，不再当成 URL 请求。JSON、JS 数组和栏目按钮保留分组信息。
- `{{函数(...)}}` 返回的请求选项在模板求值后再次解析，修复七猫发现页把 JSON 请求头拼入 URL 导致 401。
- 发现页合并 `ruleExplore` 与 `ruleSearch` 的字段；不再用“详情页兜底”把首页误当成榜单书籍。
- 兼容合集使用的解构箭头语法、UUID / Charset、`data:` 二进制请求、Inflater、RSA 公钥解包及部分 JavaScript 宿主接口。
- 书源变量和书籍变量分开存储，避免预取、下载、换源时用错另一书籍的 ID。
- 正文写入按书源、书籍、章节 URL 隔离；目录重排不会将旧行号缓存映射到另一章。iOS 旧缓存只迁移一次。
- 图片正文不会保存成空文本或伪装为成功，会提示更换文字版来源。
- iOS 首次打开榜单按“栏目 → 书籍”顺序加载，消除两个初始化任务互相覆盖造成的空列表；Android 切换分组加载该组首个可请求栏目，刷新失败时不再保留上一栏目书籍。

## 真实来源结果

**七猫小说**：iOS / Android 栏目 23 个，榜单和“都市”搜索各返回 10 本；抽样目录 674 章、首章 3,744 字。Android 写入缓存后重新创建缓存对象，离线回读内容一致。此前用“西游记”搜到的样本前几章为图片 EPUB，属于文本阅读器尚不支持的正文类型，不是有效文字样本。

**乐读小说**（合集两个入口）：iOS / Android 栏目 22 个、榜单 20 本、搜索 1 本、目录 101 章、首章 6,950 字。Android 离线回读通过。已修复发现脚本语法和 Android RSA 解包。

**望书阁网**：榜单返回 21 本；iOS 从榜单样本取得目录 1,148 章和正文 1,187 字，但本轮关键词搜索无结果；Android 搜索返回 100 条，从搜索样本取得目录 102 章、正文 6,948 字并离线回读。两端抽样书籍不同，数量不能当作逐本等价验证。

**书旗小说**：榜单和搜索各返回 10 本，但当前抽样目录为空，不能记作完整可读。

**番茄小说**：关键词搜索返回 10 本；合集的榜单和详情脚本还依赖未实现的 `Packages.java.io.ByteArrayOutputStream` 等 Java I/O 兼容能力。本轮未修完，不宣称该源完整可用。

**猫扑、飘天**：请求遇到 Cloudflare 403 或空结果。**八月文学、鸟书网、部分全本入口**：超时、连接关闭或空结果。本轮没有绕过验证页，不能将这些失败归为已修复。

发现配置解析汇总：iOS 136 个目标源中 132 个解析未报错（80 个有非空栏目、52 个无栏目），4 个报错；Android 126 个解析未报错（75 个有非空栏目、51 个无栏目），10 个报错。**这些数字不代表对应数量的书源端到端可用。**

## 使用方式

1. 导入合集后，在小说榜单顶部选择来源。顶部展示该源分组，左侧选择具体榜单或分类，右侧显示封面、来源顺序编号、书名和作者。没有来源数据的票数、热度不伪造。
2. 书籍详情和阅读页都有“缓存 / 下载”入口，可缓存后 50 / 200 章或全本，并选择预取关闭 / 3 / 10 / 20 章。
3. 下载期间显示完成数。遇到源失败会停止并保留完成章节；再次启动会跳过已缓存章节。请保持应用在前台；本轮未实现系统后台下载服务。
4. 详情或阅读页点击“换源”，搜索同名、作者一致或缺省的候选。获取新目录后优先按章节标题定位；找不到时按旧序号限定到新目录范围，从章首开始。不同来源正文不混用，原来源的缓存保留。
5. Android 可从小说首页的离线条目打开已保存目录；iOS 从书架打开。已缓存文字章节无需网络重新请求。
