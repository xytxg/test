## 本版修复

- **签到可靠性**：签到失败、HTTP 错误和网络异常不再被当成签到成功；每日自动尝试仍有记录，用户可手动重试。
- **iOS Userscripts 存储**：对同一存储键串行提交，在“保存并刷新”前等待异步写入，明确报告写入失败。
- **请求队列取消**：页面关闭、模块卸载时提前删除尚未发起的排队请求，降低无效排队。
- **独立版本更新**：独立脚本 namespace / updateURL / downloadURL，不会从上游仓库覆盖测试版。
- **持续集成**：GitHub Actions 运行类型检查、构建及测试，通过后提交打包产物。

## 第二轮优化（26.1027.1731）

- 减少由插件自己插入的 DOM 元素引起的不必要的全局扫描。
- 关键词监控增加规则数量、长度、标题长度限制，并拒绝常见高风险回溯模式（不能保证识别所有恶意正则）。
- Edge 触控大屏不再被强制套用手机弹窗布局。
- 移动端点击帖子标题默认进入原帖，另设“预览”按钮；可在设置中选择恢复标题点击预览。
- 自动加载的后续评论新增“前往原页引用或回复”链接（不冒充原生事件处理）。
- 私信归档优化本地消息回显对账索引，处理 IndexedDB 版本变更后重新打开。

## 第三轮优化（26.1027.1732）

- 私信消息分组减少不必要的数组复制。
- 消息中心增加**“清理本机存档”**，执行前确认，并且只删除当前账号的本地私信历史；不删除 NodeSeek 服务器上的任何消息。
- 自动加载评论的原页回复链接加入回归测试。

## 第四轮验证（26.1027.1733）

- 修正测试环境的脚本版本检查模拟，使其指向本仓库而不是上游。
- 增加 iOS 异步慢速保存回归测试、按账号清理 IndexedDB 存档测试。
- 进一步限制正则匹配中的超大数值量词。

### IndexedDB 回归测试
测试使用 `fake-indexeddb` 在 Node.js 中模拟真实 IndexedDB 事务，验证清除本地存档不会影响其他账号。该包**只用于测试**，不会进入用户脚本运行依赖。

## 第五轮（26.1027.1734）

- 自动更新检查共享 30 分钟缓存：打开新页面、切回前台不再重复下载元数据。
- 检查失败后自动退避 5 分钟，减轻网络异常时的请求风暴。
- 手动“检查更新”仍强制请求最新元数据；已有更新提醒不会被缓存遗漏。

## 第六轮优化（26.1027.1735）

- **按区域唤醒 DOM 观察者：** 帖子预览、徽章、过滤、阅读历史和监控只在相关节点被修改时重复扫描，减少不相关内容造成的主线程开销。
- **监控扫描改为索引查找：** 先建立帖子链接索引和缓存索引，避免逐条帖子反复遍历整个页面。
- **自动翻页跨帖校验：** 评论自动翻页只允许同一个帖子 ID 的分页链接，拒绝异常或跨帖跳转。
- 增加回归测试，确保动态追加的帖子仍能被正确增强，普通 DOM 变化不会触发无关扫描。
