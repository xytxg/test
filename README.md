## 当前版本：26.1027.1740

这轮重做了整体界面，使用中性灰与深绿色强调色，保留已有的 31 个功能模块及配置格式。

- **设置工作台**：独立分类切换、全部 / 已启用 / 已修改筛选、多关键词搜索；细项按需展开。
- **草稿与保存**：关闭后在当前页面重开会保留未保存修改，支持一键撤销和 Ctrl / Cmd + S。离开页面时由浏览器提示未保存修改；草稿不会跨页面保存。
- **避免覆盖配置**：保存只应用这次编辑过的字段，保留同页其他面板更新的设置。隐藏的停用选项不再阻挡保存；无效数字会展开定位后提示。
- **统一界面**：工具栏、消息中心、热榜、监控、历史、用户卡片、分享、快捷回复与 AI 弹窗使用同一套配色及控件规范；浅色和深色模式保持一致。
- **手机布局**：底部固定保存操作，分类可横向滑动；工具栏按钮扩大至 44px；热榜分两行放置标题与标签，并直接显示作者、浏览量和回复数。
- **维护修复**：合并重复的 UI 样式层；搜索复用节点而非反复重建表单；注册日期固定 UTC+8；文档、反馈入口、发布命令改为本分支地址。

验证范围和设计说明见 [UI_REDESIGN.md](docs/UI_REDESIGN.md)。

### 安装 / 更新

1. 点击上面的「安装 NodeSeek++ XY Test」，在用户脚本管理器里确认安装或更新。
2. 已安装原版 NodeSeek++ 时先禁用原版，保留本测试版，避免重复增强。
3. 刷新 NodeSeek / DeepFlood 页面，点击工具栏最下方的设置按钮，确认版本为 **26.1027.1740**。

如果浏览器只显示代码，请复制上方安装链接，在 Tampermonkey / 兼容脚本管理器中使用「从网址安装」。安装链接保持不变，以后仍从本仓库检查更新。

## 本版修复

- **签到可靠性**：签到失败、HTTP 错误和网络异常不再被当成签到成功；每日自动尝试仍有记录，用户可手动重试。
- **iOS Userscripts 存储**：对同一存储键串行提交，在“保存并刷新”前等待异步写入，明确报告写入失败。
- **请求队列取消**：页面关闭、模块卸载时提前删除尚未发起的排队请求，降低无效排队。
- **独立版本更新**：独立脚本 namespace / updateURL / downloadURL，不会从上游仓库覆盖测试版。
- **持续集成**：GitHub Actions 运行类型检查、构建及测试，通过后提交打包产物。

## 第二轮优化（26.1027.1731）

- 减少由插件自己插入的 DOM 元素引起的不必要的全局扫描。
- 关键词监控增加规则数量、长度、标题长度限制，并拒绝常见高风险回溯模式（不能保证识别所有恶意正则）。
- Edge 触控大屏不再被强制套用手机弹窗布局。
- 移动端点击帖子标题默认进入原帖，另设“预览”按钮；可在设置中选择恢复标题点击预览。
- 自动加载的后续评论新增“前往原页引用或回复”链接（不冒充原生事件处理）。
- 私信归档优化本地消息回显对账索引，处理 IndexedDB 版本变更后重新打开。

## 第三轮优化（26.1027.1732）

- 私信消息分组减少不必要的数组复制。
- 消息中心增加**“清理本机存档”**，执行前确认，并且只删除当前账号的本地私信历史；不删除 NodeSeek 服务器上的任何消息。
- 自动加载评论的原页回复链接加入回归测试。

## 第四轮验证（26.1027.1733）

- 修正测试环境的脚本版本检查模拟，使其指向本仓库而不是上游。
- 增加 iOS 异步慢速保存回归测试、按账号清理 IndexedDB 存档测试。
- 进一步限制正则匹配中的超大数值量词。

### IndexedDB 回归测试
测试使用 `fake-indexeddb` 在 Node.js 中模拟真实 IndexedDB 事务，验证清除本地存档不会影响其他账号。该包**只用于测试**，不会进入用户脚本运行依赖。

## 第五轮（26.1027.1734）

- 自动更新检查共享 30 分钟缓存：打开新页面、切回前台不再重复下载元数据。
- 检查失败后自动退避 5 分钟，减轻网络异常时的请求风暴。
- 手动“检查更新”仍强制请求最新元数据；已有更新提醒不会被缓存遗漏。

## 第六轮优化（26.1027.1735）

- **按区域唤醒 DOM 观察者：** 帖子预览、徽章、过滤、阅读历史和监控只在相关节点被修改时重复扫描，减少不相关内容造成的主线程开销。
- **监控扫描改为索引查找：** 先建立帖子链接索引和缓存索引，避免逐条帖子反复遍历整个页面。
- **自动翻页跨帖校验：** 评论自动翻页只允许同一个帖子 ID 的分页链接，拒绝异常或跨帖跳转。
- 增加回归测试，确保动态追加的帖子仍能被正确增强，普通 DOM 变化不会触发无关扫描。

## 第七轮优化（26.1027.1736）

- 私信列表轮询改为按页比较完整响应签名，内容无变化时跳过昂贵的 IndexedDB 合并，清理存档时失效所有签名。
- 同一批消息中的本地乐观回显与服务器确认可以正确合并，避免出现重复私信。
- 自动翻页默认每页会话最多自动追加 6 页（设置支持 0 不限制），到上限后保留已加载内容并允许手动继续，减少手机长会话 DOM 膨胀。
- 自动加载评论移除无法工作的原站动态按钮/表单，保留可用的原页操作链接；外部新窗口链接增加安全的 rel 属性。
- 为上述行为补充回归测试。

## 第八轮优化（26.1027.1737）

- **私信存档批量提交：** 同一页多个会话的数据复用一次 IndexedDB 读写事务，而不是每个联系人单独开事务；读取、去重和已读标记沿用共同的存档合并逻辑。
- **修复未排序列表：** 识别每个联系人最新消息时按消息时间比较，避免接口返回顺序不同导致联系人摘要回退。
- **移动端/旧浏览器兼容：** 不支持 `IntersectionObserver` 时，自动翻页降级为手动加载，不再让模块初始化失败。
- **长列表图片内存：** 后续页导入的图片设置懒加载与异步解码，减少移动端滚动加载高峰时的资源开销。
- 增加批量存档、账号隔离、无交叉观察器时手动翻页等回归测试。

## 第九轮优化：统一 UI（26.1027.1738）

- 新增 `src/styles/ui-refresh.css`，以统一设计变量和限域选择器重绘工具栏、监控、热榜、历史、升级提醒及私信页面。禁止全站 CSS 污染，保持 NodeSeek 原页面不变。
- 设置工作台改为左右分类、清晰文字说明、已启用功能计数、统一的输入框和按钮层级；手机采用横向分类、放大触控区域和系统安全区间距。
- 修复设置搜索框 Enter 误触发“保存并刷新”的问题，提供 Escape 清空搜索与 / 快速定位（输入框外）。
- 工具栏移除夸张渐变/发光；消息气泡调整为安静的蓝灰色，信任分保留语义但移除多重渐变背景；深色模式统一对比度。
- 增加设置页交互回归测试。界面已通过 CI 自动化验证，真实 Safari/Edge 仍需人工验收。

## 第十轮：全界面设计系统（26.1027.1739）

- 设置中心更新为带品牌标识、功能计数、即时搜索结果、可读说明、卡片和原生语义开关的工作台。支持移动端底部面板、安全区以及键盘交互。
- 设置窗口跟随站点动态切换明暗主题；功能开关保持原有数据格式与权限行为。
- 所有插件弹窗、浮动工具、分享、热榜、监控、回复和私信使用统一视觉层，移除强烈渐变，改善对比度、状态及点击目标。
- 宽屏触控设备保留桌面布局，不再仅按 hover 能力错误触发窄屏弹窗样式。
- 代码保留 GPL 许可和现有脚本升级路径，界面不引入远程字体和外部 UI 库。

### UI 设计与测试说明

设计系统集中在 `src/styles/ui-refresh.css`，设置工作台的 Shadow DOM 样式在 `src/settings/style.css`。触屏宽屏设备保留桌面工具栏和设置窗口，不因 `hover: none` 错误套用手机排版。帖子悬浮预览的明暗颜色仍保持跟随论坛本身。

自动化测试验证 CSS 作用域、设置交互、主题切换以及已有功能。**不同浏览器的实际观感、性能与无障碍仍须在真实设备验收**，尤其 iOS Safari、桌面 Edge 及系统字体缩放。
