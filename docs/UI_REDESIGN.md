# NodeSeek++ UI 设计规范与验收清单

版本：26.1027.1739

## 视觉原则
- **克制的工具风格：** 以中性灰蓝、清楚的边框层级及单一蓝色强调色为基础，不使用无意义渐变或玻璃拟态。
- **全局一致性：** 设置中心、工具栏、消息、热榜、监控、阅读历史、分享、用户卡片、快捷回复、帖内操作、AI 编辑、更新弹窗和图片预览使用一致的字体、表面、间距及交互反馈。
- **不污染原网站：** 设计层在 `src/styles/ui-refresh.css`，选择器只作用于插件创建的节点，设置页使用独立 Shadow DOM。
- **浅色/深色：** 颜色由插件局部 CSS 变量组织；设置页在论坛动态切换主题时自动跟随。帖子预览保留原论坛明暗配色。
- **可访问：** 键盘焦点状态、真正的 `checkbox` 开关、禁用态、合理的触控目标、系统减少动画设置。
- **不增添第三方 UI 依赖或在线字体。**
