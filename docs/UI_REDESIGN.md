## 这次的变化

设置页不再通过滚动定位整页功能，改为真正的分类筛选。全部 31 个模块、已有配置格式、脚本 namespace、安装与更新地址保持兼容。

视觉上采用中性灰、深绿色强调色、系统字体与明确的分隔线。设置页整合成一份 Shadow DOM 样式；插件其他界面由 `src/styles/ui-refresh.css` 统一。删除重复覆盖层，避免一处修改被后面的旧规则覆盖。没有添加运行时 UI 库、远程字体或远程 CSS。

## 行为修复

- 重新打开设置不会重置当前页面未保存的草稿；无改动时读取新配置。刷新 / 导航会触发浏览器的未保存提示（受浏览器支持及交互策略限制），不把草稿写进共享存储。
- 保存比较草稿与打开时的基线，仅覆盖修改过的字段，避免覆盖同页其他面板的新配置。同步 GM 管理器还可读到其他标签的新值；异步 iOS 管理器仍受其缓存可见性限制，不保证跨标签实时同步。
- 停用模块的字段不参加表单校验。启用模块的非法数字即使在折叠区，也会先展开、显示该字段再提示，避免保存无响应。
- 存在未保存修改时，清空缓存要求先保存或撤销，不再直接刷新丢失草稿。
- 用户注册日期以论坛 UTC+8 日历显示，消除设备时区引起的前一天偏差。
- 本分支的说明、反馈和 `make deploy` 地址指向 `xytxg/test`；保留上游署名与 GPL-3.0-only 许可。

## 验证

- TypeScript 类型检查、生产构建。
- 151 项 Node.js 单元 / happy-dom 构建产物回归测试：设置保存、异步存储、导航搜索、校验、撤销、字段合并、日期、请求、私信存档等。
- Chromium 自动化使用本地构建脚本及离线模拟论坛数据，检查 1440×1000 浅色 / 深色、390×844、320×720 深色和 844×390 布局；检查设置、热榜与分享的可见操作和横向溢出，并操作设置草稿保留及撤销。
- 本次浏览器测试未访问真实用户账户，也未发送私信、签到或发布帖子。Chromium 模拟视口不等于 iOS Safari 实机。

## 实机验收仍需关注

- iOS Safari / Userscripts 的软键盘、安全区、异步保存权限与自动更新。
- 真实论坛登录后的消息发送、监控通知、图床上传及站点动态 DOM 变化。
- 屏幕阅读器、系统大字体、浏览器页面缩放和高对比度模式。
