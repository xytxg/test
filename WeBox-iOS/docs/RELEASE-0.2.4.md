## WeBox iOS 0.2.4

- 「设置 → 源请求日志」可复制和分享最近 160 条事件。包含线路、方法、域名、HTTP 状态和系统网络阶段。记录存在内存中，省略路径、参数、请求头、正文和认证信息。
- 「设置 → 网络 → 源网络线路 → Surge VPN 接管」可使用 Surge iOS 的虚拟 DNS 地址访问 HTTPS 源。需要已运行的 Surge VPN，原域名和 TLS 校验保留。选择此线路会清除手动代理设置。
- 手动 HTTP 代理失败时，额外检查 CONNECT 响应，区分端口不可达、代理拒绝和需要认证。这个检查不发送源脚本的 POST。
- 对齐安卓宿主的请求行为。支持请求级重定向开关、保留原始查询编码、传递原始二进制正文，并在脚本要求时处理仍未解压的 gzip 响应。
- 真机 5G、Surge 规则和第三方服务端可用性需在设备网络中验证。IPA 未签名，不内置任何内容源。
