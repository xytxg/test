## WeBox iOS 0.2.6

- 首页轮播、详情操作、分类和播放器快捷栏采用 Liquid Glass，清单、搜索和导入沿用 iOS 系统组件。设置支持浅色、深色和跟随系统。
- 首页可直接续播当前源最近观看的内容。资料库可搜索、按源筛选、删除单条或清除当前过滤范围的历史。续播尝试恢复上次使用的播放资源。
- 各内容源的搜索结果按完成进度显示。首页保留可读分类，过滤重复条目，在刷新期间保留已加载内容。
- 播放器支持全屏、拖动进度、双击两侧快进或快退。竖屏视频中央上滑播放下一集、下滑返回上一集，可在播放设置中关闭。支持线路切换、音轨、字幕、AirPlay 和画中画入口。
- 源管理新增独立批量导入入口，保留单文件和链接导入。支持 WeBox、Widget 和 XPTV JS 格式。

最低需要 iOS 17。IPA 未签名，需自行签名后安装。应用由你导入的 JS 提供内容。配套截图使用本地测试数据。
